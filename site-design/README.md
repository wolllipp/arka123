# АРКА 123 — макет сайта (песочница дизайна)

Запуск (нужен локальный сервер — 3D грузит текстуры, а видео прелоадера
требует сервер с поддержкой Range-запросов, иначе Safari его не проиграет):

```bash
cd "~/Downloads/MediaLine /site-design"
npx http-server@14.1.1 -p 8123 -c-1
# открыть http://127.0.0.1:8123
```

Не используйте `python3 -m http.server`: он не умеет Range, и в Safari прелоадер пропускается.

- `index.html` — разметка всех блоков
- `styles.css` — «Арочная система»: токены цвета/типографики, компоненты
- `main.js` — прелоадер (ролик + цикл ожидания), раскрытие окна на скролле, появление блоков
- `booking.js` — бронирование: дни и часы из API, цена с сервера, форма, отмена по коду. Нужен запущенный `../arka-backend` на `http://127.0.0.1:8090` (адрес можно переопределить через `window.ARKA_API`)
- `room.js` — 3D-зал на Three.js: обрезка ближних стен, 4 рассадки, день/закат, вид изнутри
- `assets/img` — сжатые фото (на `p01.jpg` убрана рекламная плашка), `assets/tex/view.jpg` — вид из окна

Отзывы — демо-данные. Слоты, цены и брони — настоящие, из бэкенда.

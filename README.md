# АРКА 123 — сайт под ключ

Тестовое задание MediaLine: сайт для аренды зала АРКА 123 под мастер-классы и семинары. Адрес — Минск, ул. Мстиславца, 10, напротив Национальной библиотеки. Слоган — «Встречаемся напротив Библиотеки».

Выполнены все пять частей задания.

**Сайт: https://arka123-hzoq.onrender.com** (первое открытие календаря — до минуты: бесплатный сервер просыпается).

## 1. Анимация логотипа

**Идея — «Арка строится, и сквозь неё загорается свет».** Это отсылка к залу, где огромные арочные окна смотрят на Библиотеку. Сначала прорисовывается фундамент. Потом из основания вырастает колонна-«1», над ней смыкается свод, цифры «2» и «3» поднимаются из маски. В проёме на мгновение вспыхивает тёплый свет заката с силуэтом Библиотеки, затем рядом «встаёт» надпись и слоган. Раскадровка с таймкодами лежит в `prompts/01-logo-hyperframes.md`.

- Ролик собран в HyperFrames: `logo-motion/renders/arka123-logo-A.mp4`.
- На сайте ролик работает как **прелоадер** при загрузке. Его укороченная петля служит **ожиданием вместо спиннера**, пока сервер проверяет бронь.
- При **наведении** на логотип в шапке знак перерисовывается заново. На тач-устройствах и при «уменьшении движения» эффект отключён.

## 2. Фирменный персонаж — кот Мстислав

Выбран второй путь задания: своя идея вместо девушки-ведущей.

**Мстислав — дымчато-серый кот, хранитель зала напротив Библиотеки.** Коты веками жили в библиотеках и берегли книги, и Мстислав продолжает эту традицию на другой стороне улицы: встречает гостей у арки, провожает в зал и греется на подоконнике арочного окна с видом на Библиотеку. Имя взято от улицы Мстиславца. Пётр Мстиславец был первопечатником, соратником Ивана Фёдорова, так что у кота «книжная» родословная.

Кот передаёт уют и спокойствие, а это важно тем, кто проводит мастер-классы и лекции. Образ повторяет айдентику: серая шерсть — это графит стен, янтарные глаза — закат в арках, а на тёмно-синем ошейнике висит кулон-арка «123».

- Полная идея, библия персонажа и все промты — в `prompts/03-cat-mstislav.md`.
- Референс образа: `prompts/refs/mstislav-ref.jpg`.
- На сайте кот стоит в блоке бронирования: вырезан из фона, без рамки, с тёплым свечением и едва заметным «дыханием».

## 3. Помещение в 3D

Интерактивная модель зала на Three.js, собранная по реальным размерам: 123 м², два окна 4 × 3,5 м, потолок 4,5 м, вид на Библиотеку.

- Зал можно вращать и приближать.
- Четыре рассадки: пустой зал, лекция рядами (48 мест), общий стол (24), группы (36).
- Режимы «день» и «закат», режим «встать внутри зала».
- Подписи привязаны к точкам модели.

## 4. Герой бренда — видео на скролле

Первый экран — арочное окно. Оно раскрывается при прокрутке, и дальше прокрутка «ведёт» видео кадр за кадром, в стиле промо-страниц Apple:

1. камера наезжает с променада на арочные окна зала;
2. проходит через пустой зал к окну;
3. окно днём перетекает в то же окно на закате;
4. в кадр запрыгивает Мстислав, садится на подоконник и смотрит на Библиотеку.

Пролёт собран из реальных фото зала, поэтому помещение не искажено. Финальная сцена с котом сгенерирована нейросетью от последнего кадра пролёта, так что окна на стыке совпадают. Промты — в `prompts/04-final-scene.md`, сборка — `frontend/tools/build-film.py`.

## 5. Сайт

- **Прелоадер** из ролика логотипа, затем первый экран со слоганом.
- **Блоки:** шапка (на телефоне — меню), «О пространстве», 3D-зал, форматы, тарифы, услуги и цены, галерея, отзывы, бронирование, «Как добраться» с картой и пешеходным маршрутом от метро, футер.
- **Фирменный стиль:** знак и надпись, слоган, цвета логотипа (графит-синий, молочный, закатный акцент), шрифты Manrope и Inter, арка как единственная декоративная форма.

**Бронирование работает по-настоящему, с собственным бэкендом:**

- календарь на 90 дней;
- свободные часы обновляются в реальном времени;
- цена считается на сервере;
- кнопка тарифа сразу отмечает его длительность;
- форматы рассадки, которые не вмещают гостей, недоступны;
- защита от двойной брони;
- письма гостю и администратору;
- страница брони по ссылке из письма;
- «Добавить в календарь»;
- отмена с подтверждением (онлайн — не позднее чем за сутки);
- панель администратора `/admin`.

## Запуск

```bash
# 1. backend
cd arka-backend
cp .env.example .env          # заполнить пароли и JWT_SECRET
docker compose up -d          # Postgres :5435, Redis :6380, Mailpit :8025
set -a; . ./.env; set +a
mvn spring-boot:run           # http://127.0.0.1:8090

# 2. сайт (в другом терминале)
cd frontend
npm install
npm run dev                   # http://127.0.0.1:8123
```

Подробности — в `arka-backend/README.md` и `frontend/README.md`.

## Деплой (Render)

`render.yaml` поднимает всё одной кнопкой: сайт (static), API (Docker, `arka-backend/Dockerfile`), PostgreSQL и Redis.

1. Render → **New → Blueprint** → выбрать этот репозиторий.
2. Задать `ADMIN_PASSWORD`, остальное подставится само.
3. Если Render выдаст адреса не такие, как в `render.yaml`, нужно поправить переменные и пересобрать:
   - `VITE_API_URL` у сайта;
   - `CORS_ORIGINS` и `SITE_URL` у API.
4. Чтобы письма уходили по-настоящему, добавить API переменные `SMTP_*` и `MAIL_FROM` (пример в `arka-backend/.env.example`). Без них бронь сохраняется, просто письмо не отправляется.

Ограничения бесплатного тарифа:
- API засыпает после 15 минут без запросов, первое открытие календаря занимает до минуты (сайт об этом предупреждает);
- бесплатная база живёт 30 дней.
